# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it confidentially by contacting `techamit109@gmail.com`.
Please do not disclose security issues through public GitHub issues or discussions until they have been reviewed and addressed.
