### Added
- Core `revllm` library supporting baseline Euler, midpoint, midpoint-theta, leapfrog, and Hamiltonian dynamics.
- Memory-efficient reversible autograd custom functions.
- Chunked cross-entropy with memory isolation.
- Fully automated batch probing and diagnostic sweeps.
- Google Colab free-tier pipeline with Google Drive state persistence and resume.
- Comprehensive unit and property test suite.
